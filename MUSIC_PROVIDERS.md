# Музыкальные источники DAGSTUDIO PLAYER

## Доступность в России
Все запросы поиска и официальной ленты Audius идут через API проекта
https://pl.dagstudio.ru. Android-клиент использует проверенный HTTPS fallback
при DNS-сбое для домена DAGSTUDIO. Это НЕ гарантия доставки музыки от любого
внешнего поставщика: каталог может вернуть HTTP 403/404, региональное ограничение,
либо временно быть недоступным для сервера.

## Подключение музыки
- Audius: официальный API, поиск, новые релизы, популярное; резервный
  публичный адрес discoveryprovider.audius.co. Воспроизведение использует
  разрешённые публичные stream URL, с TLS и проверкой сервера.
- Jamendo: необязательный 8-й источник (Creative Commons). Требует **свой**
  JAMENDO_CLIENT_ID (переменная окружения PHP на сервере). Не используйте
  открытый тестовый client_id из документации в production. Стримы принимаются
  только с HTTPS storage.jamendo.com и дочерних хостов; для песен Jamendo
  в интерфейсе отображается источник и ссылка на CC-лицензию.
  Скачивание треков Jamendo в этой версии отключено: наличие stream URL
  не означает разрешение download.
- SoundCloud: официальный каталог-переход, пока нет зарегистрированного
  API-приложения и соответствующего лицензированного потока.
- MusicBrainz: каталог-переход и проверка дискографии; это НЕ хранилище
  аудиозаписей. Для API нужен User-Agent и лимит 1 запрос в секунду.
- Звук-М и Kavkaz Music: переход к премьерам и архивам на сайтах
  издателей. Не использовать их веб-страницы как незаявленные MP3 API:
  для встроенного проигрывания нужны условия лицензирования/API.
- Кавказ Хит: ссылка на официальный радиоэфир. Встраивание/ретрансляция
  возможна только при разрешении радиостанции.

## Проверки перед отметкой "Работает"
1. API возвращает matching_tracks > 0 для конкретного запроса.
2. HEAD запрос к прокси отвечает 200/206 с audio/*.
3. Устройство реально проигрывает больше 30 секунд без внезапного пропуска.
4. Тест в России без VPN через мобильного оператора и TEYES CC3.
5. Повторный запуск из кэша; перемотка через HTTP Range.

Мониторинг: GitHub Actions / Music Source Health — каждые 6 часов.
Тесты не утверждают доступности всех семи/восьми источников. Встроенное
воспроизведение SoundCloud, каталогов правообладателей и MusicBrainz не
заявляется до реализации согласованного и проверенного API.
