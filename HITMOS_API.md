# DAGSTUDIO PLAYER: собственный Hitmos API (прототип)

Дата: 25.11.2026.

## Адрес

GET https://pl.dagstudio.ru/hitmos-api.php?q=Miyagi&page=1

Также доступен POST с JSON вида {"q":"Miyagi","page":1}.

Ответ: JSON с полями success, provider, status, upstream_http, count, audio_verified, data.

- candidates_found: поддерживаемый HTML дал совпадения с разрешёнными HTTPS-аудиоссылками; это **не** означает, что поток доступен.
- blocked: внешний сайт ответил HTTP 401/403/429.
- unreachable: запрос к внешнему сайту не прошёл.
- redirect_unsupported: сайт возвращает редирект; переходы на другой хост намеренно запрещены.
- no_playable_tracks: сайт ответил HTTP 200, но адаптер не обнаружил поддерживаемые ссылки.
- upstream_error: прочая ошибка внешнего сайта.
- invalid_query: некорректный поисковый запрос.

В запросе нет параметра URL внешнего ресурса. Хост фиксирован: ru.hitmos.site. Адаптер не эмулирует авторизованного пользователя, не обходит антибот-проверки, не скачивает и не ретранслирует музыку. Разрешаются только явные HTTPS-аудиоссылки с допустимым расширением и из проверенного списка хостов (по умолчанию только ru.hitmos.site; дополнительные лицензированные аудиодомены задаются отдельно через HITMOS_AUDIO_HOSTS).

## Статус подключения

Проверка 25.11.2026: прямые запросы к ru.hitmos.site с GitHub Actions возвращали HTTP 403; попытка поиска с хостинга DAGSTUDIO — HTTP 0, без результатов. Адаптер подготовлен, но **не добавлен в рабочую поисковую выдачу**, пока реальный поиск и легальный аудиопоток не подтверждены.

Рабочий поиск Muzofond и существующие плейлисты не изменяются. Unit-тест tests/hitmos-adapter-test.php использует только искусственный HTML-образец для проверки безопасного разбора; его прохождение нельзя считать подтверждением работы внешнего сайта.

Чтобы включить полноценный Hitmos как второй источник поиска, понадобится открытый/разрешённый endpoint поиска или API-ключ, подтверждённая структура реальной выдачи и независимая проверка аудиопотока с Range-запросом. Никаких неизвестных CDN или обходов HTTP 403 автоматически не добавлять.
