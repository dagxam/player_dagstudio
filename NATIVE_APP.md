# DAGSTUDIO PLAYER — нативное приложение

В репозитории используется Capacitor 8. Интерфейс HTML/CSS/JS упаковывается внутрь Android/iOS-приложения, а серверные функции остаются на https://pl.dagstudio.ru.

## Что хранится внутри приложения

- интерфейс DAGSTUDIO PLAYER;
- CSS;
- JavaScript;
- изображения и иконки;
- Font Awesome.

PHP, SQLite, поиск по внешним источникам и потоковый proxy внутрь APK/IPA не копируются. Приложение обращается к production API на pl.dagstudio.ru.

## Android

Workflow **Build Android APK** автоматически собирает установочный APK и сохраняет его как GitHub Actions artifact **DAGSTUDIO-PLAYER-Android**.

Текущая автоматическая сборка — debug-signed APK, пригодный для прямой установки и тестирования на телефоне, планшете и Android-магнитоле. Для постоянных production-обновлений без переустановки нужен постоянный release keystore; его следует хранить только в GitHub Secrets, а не в репозитории.

## iPhone / iPad

Workflow **Prepare iOS App** вручную проверяет нативную iOS-сборку без подписи. Для настоящего устанавливаемого IPA потребуется Apple Developer signing certificate и provisioning profile.

## Локальная оболочка

Команда:

```bash
npm install
npm run native:web
```

создаёт папку `www/` для Capacitor. Она не коммитится в Git и пересобирается из актуальных файлов сайта.


## Офлайн-кэш музыки

Нативное приложение хранит аудио в приватной папке приложения через Capacitor Filesystem (Directory.Data) и скачивает файлы через Capacitor File Transfer.

Поведение:

- все треки, добавленные в плейлисты, ставятся в очередь локального сохранения;
- онлайн-трек после начала прослушивания также сохраняется на устройстве;
- при пропадании сети плеер автоматически использует локальную копию;
- снимок плейлистов хранится локально, поэтому ранее синхронизированные плейлисты доступны без сети;
- при удалении трека или плейлиста локальный файл удаляется, если этот же трек больше не используется в другом плейлисте;
- файлы лежат во внутреннем хранилище приложения и удаляются Android при удалении приложения.
