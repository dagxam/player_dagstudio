# DAGSTUDIO PLAYER — TEYES CC3: план надёжности

Этот план остаётся в репозитории и обновляется после каждого этапа. Его цель — стабильная музыка на магнитолах 1024×600 и 1280×720, при слабом мобильном интернете, при переключении на навигатор и при пробуждении устройства.

## 1. Воспроизведение и аудиокэш — в работе
- [x] При зависании запросов пауза действительно останавливает загрузку; ручной повтор не должен запускать несколько потоков.
- [x] Текущий трек на паузе можно приоритетно загружать в локальный кэш без автоматического проигрывания.
- [x] Мониторинг движения позиции воспроизведения, ограниченные попытки восстановления и диагностика причин.
- [x] На современном Android WebView сначала используем HTTP Range и локальный кэш, а на старых оставляем совместимый поток 200.
- [x] Скачивание Android-кэша во временный файл с публикацией только после завершения.
- [x] Более экономная потоковая передача PHP-прокси; метрика задержки первого байта для диагностики.
- [x] Исправлен обработчик неудачного старта трека (область видимости URL); таймер ожидания восстанавливает поток и при самопроизвольном `paused` в WebView.
- [x] Повторные сбои помечают радиосеть как слабую на 3 минуты даже без Network Information API; `playing` без продвижения позиции больше не сбрасывает счётчик попыток.
- [x] PHP-прокси проверяет начальную позицию в `Content-Range`, поддерживает HEAD без скачивания трека; устаревший `stream.php` использует тот же безопасный прокси.
- [x] Нативное скачивание кэша использует повышенные тайм-ауты бездействия (120 с) при слабой сети и 45 с на подключение, сохраняя атомарную публикацию файла.
- [x] Автоматический браузерный тест воспроизводит отказ audio.play() и проверяет, что восстановление запускается без исключений в JavaScript.
- [ ] Физический тест TEYES CC3: 30–60 минут непрерывного звука, 4G/2G, пауза при загрузке, потеря и восстановление сигнала, переход между песнями.
- [ ] При подтверждении необходимости внедрить Android Media3/ExoPlayer как самостоятельный нативный движок со стабильной MediaSession, не ломая веб-плеер. **Media3 ещё не внедрён.** Это изменение потребует новой APK, OTA недостаточно.

- [ ] Защита от двойных восстановлений после возобновления сети и питания.

### Критерии приёмки
1. 1024×600, 1280×720 и телефон: удобные элементы, без горизонтальной прокрутки.
2. Под нагрузкой и при слабом интернете основной поток приоритетнее фонового кэширования.
3. Пауза останавливает звук/зависший сетевой запрос без неожиданного повторного Play.
4. Нет незапрошенного OTA-перезапуска; сохраняется состояние.
5. Изменения в GitHub → FTP-деплой → Android OTA; изменения Java/Android плагинов требуют APK.
6. Готовность к использованию на TEYES CC3 нельзя считать подтверждённой без теста на самой магнитоле.
